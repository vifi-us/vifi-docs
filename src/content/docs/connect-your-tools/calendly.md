## What it does

- **Check Calendly availability.** The agent looks at your chosen event type for open slots in a date range.
- **Book Calendly appointment.** After confirming a time, the agent creates a Calendly invitation. Calendly sends the caller its usual confirmation.

## Connect

1. Open **Integrations** and click **Connect** on Calendly.
2. Sign in to Calendly and approve access.

## Set the event type

1. Open **Automations** and find **While your agent is on a call**.
2. Switch on **Check Calendly availability** and pick the **event type** the agent should use, such as "30-minute consultation".
3. Switch on **Book Calendly appointment**.

::screenshot[The Calendly automation card with the event type selected]

## What the agent needs from the caller

To book, the agent collects the caller's name and an email address for the invitation. If the caller won't give an email, the agent offers to take a message instead.

## Tips

- One event type per workspace works best. If you offer several, name the one the agent uses in your [business description](/your-agent/business-profile/) so the agent can explain it.
- Calendly's own rules for buffers and daily limits apply.
