## The call shows "Processing"

Summaries usually take under two minutes. Give it five. If it's still processing after that, refresh the page; if it changes to **Unavailable**, see below.

## The call shows "No transcript"

Nobody spoke, or the call ended before audio arrived. Hang-ups and robocalls look like this. There's nothing to summarise, so no briefing is sent. If real conversations show this, see [Audio problems](/fix-a-problem/audio-problems/).

## The call shows "Unavailable"

The summary couldn't be generated. Wait a few minutes and refresh; ViFi retries. If it stays unavailable, [contact support](/fix-a-problem/contact-support/) with the call link.

## The summary exists but no email or text arrived

1. Open **Settings**, then **Notifications**. Check the recipient is listed and the switch for email or SMS transcripts is on.
2. For text, check the number is a mobile number and hasn't replied STOP to ViFi. The Notifications page shows if texts to your own number are switched off.
3. Check the spam folder for email.
4. If you rely on Slack, Discord, HubSpot, or Gmail for the briefing, check the integration's **Activity** tab. See [An integration disconnected](/fix-a-problem/integration-disconnected/).

## Very short calls

Calls with only a few words of conversation may be treated as missed rather than answered, which triggers missed-call automations instead of the summary ones.
