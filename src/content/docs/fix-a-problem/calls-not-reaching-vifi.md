title: Calls aren't reaching ViFi
description: The agent never answers, or callers get voicemail. Work through these in order.

  order: 1
---

## 1. Is the caller approved?

During the free trial, only [approved callers](/calls-and-callers/approved-callers/) get through. Calls from any other number are not answered. Test from an approved phone, or subscribe.

## 2. Does the ViFi number itself answer?

Call your ViFi number directly (it's on **Channels**), from an approved phone if you're on the trial.

- **It answers:** ViFi is fine. The problem is forwarding. Go to step 3.
- **It doesn't answer:** check the dashboard for **Phone provisioning in progress** or **No live phone number yet**. If the number was set up more than fifteen minutes ago and still doesn't answer, [contact support](/fix-a-problem/contact-support/).

## 3. Is forwarding on?

Dial the "turn on" code again from the phone whose calls should forward. Listen for the confirmation tone. Codes are in [Forward your calls](/start-here/forward-your-calls/).

For overflow forwarding, let the test call ring until your phone stops ringing. Some carriers only forward after a set number of rings; ask your carrier to shorten the delay if callers are hanging up first.

## 4. Is the caller blocked?

Check [Blocked callers](/calls-and-callers/blocked-callers/), including the automatic blocks with the **Auto** tag and the recent rejected calls list.

## 5. Has the trial or subscription lapsed?

If the dashboard shows **Billing needs attention** or the trial has ended, callers hear a short unavailable message. See [Your free trial](/billing/free-trial/) and [Invoices and payment](/billing/invoices-and-payment/).

## 6. Has the stop-limit been reached?

An extra-usage stop-limit pauses calls for the rest of the period. See [Usage and guardrails](/billing/usage-and-guardrails/).

## Still stuck?

Note the time of a failed call and the number it came from, then [contact support](/fix-a-problem/contact-support/).
