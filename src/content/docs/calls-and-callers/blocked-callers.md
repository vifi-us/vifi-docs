Blocked numbers are rejected before the agent answers, so they never use your minutes and never appear in your briefings as real conversations.

Open **Callers** in the sidebar, then **Blocked callers**.

::screenshot[The Blocked callers page with the list, the automatic protection switches, and recent rejected calls]

## Blocking a number by hand

1. Click **Block a number**.
2. Enter the phone number in full.
3. Optionally add a reason. Only your team sees it, for example "Robocall pitching SEO services".
4. Save.

You can also block from a caller's [profile](/calls-and-callers/callers/) or from a call page.

## Letting ViFi block for you

Two switches on the page let ViFi block obvious abuse automatically. Every automatic block appears in the list with an **Auto** tag and can be undone.

- **Block likely spam callers.** Numbers that behave like robocallers, for example calling and hanging up the moment the agent speaks, are blocked after a pattern is detected.
- **Repeat-call guard.** If one number calls more than a set number of times within ten minutes, further calls are rejected for a while. Set the threshold to suit your business.

## Rejected calls

The **Recent rejected calls** list shows what was blocked in the last seven days, so you can check nothing legitimate was caught. Unblock a number with one click.

## Bans

Blocking is per workspace. Serious abuse can also be reported to ViFi, which can ban a caller across the platform. Email [support@vifi.us](mailto:support@vifi.us) with the number and a call link.
