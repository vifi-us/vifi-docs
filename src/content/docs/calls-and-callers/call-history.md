Open **Calls** in the sidebar. Every call your agent handled is listed, newest first, including test calls from the browser.

## Finding a call

- **Search by caller number.** Type part of the number.
- **Filter** by status or by whether the call has tags.
- Click a row to open it. On wide screens the detail opens beside the list so you can move through calls quickly.

::screenshot[The Calls list with the search box, filters, and status badges]

## Status badges

Each call shows where its analysis is:

| Badge | Meaning |
|---|---|
| **Processing** | The call has ended and ViFi is writing the summary. Usually under two minutes. |
| Ready (no badge) | Summary, action items, and transcript are available. |
| **No transcript** | The call ended before anyone spoke, or audio never arrived. Common with hang-ups. |
| **Unavailable** | Analysis couldn't run. If you see this often, see [I didn't get a briefing](/fix-a-problem/no-briefing/). |

## Archived calls

A call can be archived from its detail page to keep the list tidy. Archived calls show a notice at the top and can be found with the filter.

## Who can see calls

Everyone on the team can read calls. Only roles with recording access can play recordings. See [Team and roles](/team-and-account/team-and-roles/).
