Open **Callers** in the sidebar. Every phone number that has reached your agent gets a profile. The agent reads it at the start of each call, so a returning caller gets recognised.

::screenshot[The Callers list with a search box and a row per caller]

## The profile

- **Lifecycle.** Whether this is a first-time caller, a returning one, or someone who hasn't called in a while. Callers without a known number show as **Unidentified**.
- **Sentiment trend.** How their calls have felt over time, from the summaries.
- **AI-extracted facts.** Details the agent picked up on calls, such as "prefers morning appointments" or "has a 2019 Honda Civic". The agent uses these next time. You can remove any fact that's wrong.
- **Open follow-ups.** Action items from their calls that haven't been closed.
- **Owner notes.** Your own notes about the caller. The agent can see these too, so "VIP, always transfer to Dana" works.
- **Tags.** Labels you add to group callers.
- **Timeline.** Every call from this number, with links to each briefing.

## Searching

Search by phone number. Names aren't reliable identifiers, so ViFi organises by number. When the agent learned a caller's name on a call, the list shows it with the number underneath.

In the [ViFi app](/start-here/mobile-app/) <span class="status-pill status-pill--coming-soon">Coming soon</span>, tap **Callers** at the top of the **Calls** tab, or **More**, then **Blocked & approved callers**. Search there by name, number, or tag. The same screen leads to **Blocked callers**, which has its own search by part of the number or a word from the note, and to your approved callers.

## Blocking a caller

Use **Block** on the profile to stop this number reaching your agent. Blocked calls are rejected before they're answered and don't use minutes. See [Blocked callers](/calls-and-callers/blocked-callers/).

## Privacy

Caller facts are drawn from what the caller says on the call. If a caller asks you to delete their information, email [support@vifi.us](mailto:support@vifi.us) with the number. See [Data and privacy](/reference/data-and-privacy/).
