If callers ask about specific items and prices, a menu gives the agent exact answers instead of a paraphrase from a document. It works for restaurants, salons, repair shops, and anyone with a price list.

Open **Menu** in the sidebar.

## Adding items

1. Click **Add item**.
2. Give it a **category** such as Pizza, Drinks, Sides, or Services.
3. Enter the **name**, **price**, and a short **description**.
4. Mark it unavailable if you're out of it or it's seasonal.
5. Save.

::screenshot[The Menu page with items grouped by category]

## How the agent uses it

With **Look up menu and services** turned on (see [Call behavior](/your-agent/call-behavior/)), the agent searches the menu when a caller asks about an item, a price, or what's available. It reads the price as you entered it and mentions the description if it helps.

## Menu or knowledge base?

| Use the menu for | Use the knowledge base for |
|---|---|
| Items with a fixed price | Anything that needs explaining |
| "Do you have gluten-free crust?" | "What's your cancellation policy?" |
| Availability that changes often | Long documents and web pages |

Many businesses use both: the menu for the price list, articles for the questions around it.

## Who can edit

Admins and Members can manage the menu. Viewers can see it.
